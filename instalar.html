Gestão de Segurança do Trabalho

✔ O app já está instalado neste aparelho. Abra pelo ícone na tela inicial.

Android (Chrome)

  1. Abra este link no Chrome.
  2. Toque em Instalar aplicativo acima. Se o botão não aparecer, toque nos três pontinhos do Chrome e escolha Instalar aplicativo (ou Adicionar à tela inicial).
  3. Abra o app pelo ícone na tela inicial e entre com seu login.

iPhone (Safari)

  1. Abra este link no Safari.
  2. Toque no botão Compartilhar (quadrado com seta para cima).
  3. Escolha Adicionar à Tela de Início e toque em Adicionar.
  4. Abra o app pelo ícone e entre com seu login.

Ler no celular

Aponte a câmera do celular para o QR code.

Use sempre o ícone do app, não o navegador. Se perder o celular, avise o administrador para desativar seu login.
